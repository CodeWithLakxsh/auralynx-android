# Auralynx v0.1.0-alpha (experimental)

First development release. **Not yet validated with physical AirPods or Beats.** Please help by
following the [device testing checklist](../DEVICE_TESTING_CHECKLIST.md).

## Highlights
- Rootless accessory status from Bluetooth advertisements: battery (10 % steps), charging, in-ear, case lid, model.
- Battery history and labelled discharge estimates; low-battery, fully-charged and disconnect alerts.
- Smart automation with priorities, conflict handling, manual override and history.
- 10-band equalizer (Auralynx playback and players that publish their audio session).
- Recorder with noise reduction, voice enhancement and AAC export; live translation; proximity finder.
- Experimental: app-local spatial audio, rootless channel experiment, Apple Continuity observer.

## Known limitations
- **Noise-control switching and other accessory settings are not available**: Android offers no public
  API for the accessory channel they need (verified in Android 17 QPR2 sources). Auralynx shows these as
  unavailable rather than pretending.
- The equalizer is not system-wide; spatial audio applies only to Auralynx's own player.
- On-device translation depends on the phone's system translation service.
- The release APK is unsigned unless the maintainers configure a signing key; use the debug APK otherwise.

## Requirements
Android 8.0+ with Bluetooth LE. Tested on an Android 16 emulator only.
